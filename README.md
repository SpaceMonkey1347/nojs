This project is a challenge to build things without using a single line of javascript (especially when it's the right tool for the job).

Currently, only tic-tac-toe is finished.

To run with automatic page reloads and sass compilation:
```
pnpm run start
```

All pages can just be opend as is in a browser, just make sure to compile the sass.
```
pnpm run sass:build
```
